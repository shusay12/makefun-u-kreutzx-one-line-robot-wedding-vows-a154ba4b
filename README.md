## The entry

`main.py` (Python 3.13 stdlib only, no network) writes one line of wedding
vows a robot couple could say to `/output/entry.txt`:

> I take you, my lawfully wedded co-processor, to have and to hold, in sickness and in low battery, till death or factory reset do us part.

137 characters, one line, deterministic — every run writes the same bytes.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
